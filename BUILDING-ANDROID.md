# Working from an Android phone

## What you can do on the phone
1. Download and unzip `PlaystationMax-v0.3.zip`.
2. Edit `data/catalogue.json` with a text editor.
3. Keep artwork you own in `assets/`.
4. Review/edit the C++ source.
5. Use a browser to read the official toolchain and SDL-PS4 documentation.

## What is not realistic to promise on Android alone
OpenOrbis's documented setup expects a supported host toolchain (Clang/LLD, Python tools, and platform-specific packaging tools). The published workflow is primarily documented for Windows, Linux, and macOS. An Android terminal environment may be possible to experiment with, but it is not a verified, supported one-click build path for PS4 PKGs. Do not assume Termux can create a compatible package without adapting and testing the entire toolchain.

## Recommended workflow
1. Keep Android as the source-editing/catalogue device.
2. When available, use a Windows/Linux/macOS computer or a remote Linux development machine to build.
3. Install a published OpenOrbis release from the official repository and follow its own README.
4. Build the toolchain's unchanged `hello_world` sample first.
5. Build/port SDL-PS4 and its dependencies as documented by that project.
6. Replace the sample's source with `src/main.cpp`, retaining the sample's known-good linker and package settings.
7. Package using the scripts/tools from that exact toolchain release.
8. Test on the specific console and homebrew environment.

## PKG generation checklist
A valid project needs more than a `.cpp` file:
- PS4-targeted executable/`eboot.bin`
- `param.sfo` with consistent title/application metadata
- required modules/assets/dependencies
- package project (GP4 or the release's equivalent workflow)
- `.pkg` generated by compatible packaging tools

The exact command line and metadata depend on the sample and release. This project deliberately does not include made-up commands or firmware claims.

## Check a Linux build environment
From the project folder, run:

```sh
./check-build-env.sh
```

This is a diagnostic only. It does not compile or package the app. A working PS4 toolchain and the matching SDL-PS4 build setup are still required. Do not upload private signing keys or console account credentials to a cloud IDE.
